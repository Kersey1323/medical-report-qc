# 医学报告质控 Web · 风格与交互审核原型

2026-10-16。直接用浏览器打开 [index.html](./index.html)，无需启动服务、安装依赖或联网。所有样式、图标与脚本都已内嵌。面向 1280 / 1440 / 1920px 桌面浏览器审核。

这是已审核通过的独立设计交付物，正式前端已按此方向实施，使用 React + TypeScript + Vite + Tailwind CSS。原型采用原生 HTML/CSS/JS，以便单文件离线审核。

## 选型依据

实际访问 StyleKit 风格目录及九个风格详情页，比较了企业简洁、数据密集、固定侧边栏、仪表盘布局、Notion、便当盒、分屏、极简扁平、卡片堆叠。最终采用一个统一视觉基底，按组件职责借用布局与信息组织规则。

| 参考 | 角色 | 应用范围 |
| --- | --- | --- |
| [Corporate Clean / 企业简洁](https://www.stylekit.top/zh/styles/corporate-clean) | 全局视觉基底 | 浅色画布、白色内容区、蓝色主按钮、边框、输入框、弹窗 |
| [Fixed Sidebar / 固定侧边栏](https://www.stylekit.top/zh/styles/sidebar-fixed) | 应用框架 | 256px 固定侧栏、收起状态、当前位置、顶栏操作 |
| [Data Dense / 数据密集](https://www.stylekit.top/zh/styles/data-dense) | 数据操作密度 | 任务表、报告明细、复核任务表、筛选、搜索、分页、状态和行内操作 |
| [Split Screen / 分屏布局](https://www.stylekit.top/zh/styles/split-screen) | 原文与结果对照 | 左侧原文、右侧建议；复核工作区增加任务内建议列表 |
| [Notion Style](https://www.stylekit.top/zh/styles/notion-style) | 长文本阅读规则 | 报告正文、检索报告全文、来源、折叠审计信息、稳定的交互反馈 |
| [Bento Grid / 便当盒网格](https://www.stylekit.top/zh/styles/bento-grid) | 仅参考模块分区 | 工作台主列展示任务，辅列展示快捷入口与待复核分布，统一间距 |

这些是设计参考，**不是同时套用六套完整主题**。全站使用同一套色板、字体和控件。分屏不采用展示站的大图与全屏高度；Bento 不采用悬浮、放大、渐变；Notion 不采用没有拖拽功能的假手柄；企业风不采用营销 Hero 的大标题与大留白。仪表盘参考的深色侧栏和卡片堆叠的遮挡动效不适合当前场景，因此未采用。

## 核心尺寸与视觉规则

- 固定侧栏 256px，收起 76px；顶部栏 58px。
- 页面操作与面包屑同一行；筛选与搜索共用表格工具栏。正文没有重复页面大标题和独占行的页级操作按钮。
- 画布 `#f5f7fa`，侧栏 `#f8fafc`，内容区白色；主要操作 `#2855bd`，正文 `#202b3b`，辅助文字 `#647287`，边框 `#e3e8ef`。
- 区块间距 16–20px，内部间距 16–24px；按钮 33px，卡片圆角 9px，输入框和按钮圆角 6px。
- 表格文字 12px；报告正文 14px、行高 2.1、最多 72ch；ID 与数字使用等宽字体。
- 状态同时提供文字和图标。按钮具有 hover、active、focus、disabled 状态。
- 仅颜色变化，无卡片浮起或内容缩放；支持 reduced-motion。
- 弹窗、抽屉支持 Escape、遮罩关闭、焦点约束与返回触发位置；背景使用 inert。

## 建议审核顺序

1. 打开首页，检查侧栏、顶栏、指标条、近期任务表及间距。
2. 进入「批量任务」，切换状态并搜索，点击某个任务查看报告明细。
3. 打开报告，切换诊断 / 字符 / 语法 / 定位，检查原文与建议的并排阅读体验。
4. 点击「检索报告 · Top 10」，查看全文与来源布局。
5. 进入「人工复核」，选择任务，在建议队列中切换并试用复核操作。报告详情与复核操作区已增加「下一条」，在同一任务内保留检查项目继续查看；末条禁用。生产复核入口始终按任务聚合。
6. 查看「单份质控」和导入弹窗，再到「组件与风格」审核错误、空状态及控件层级。

## 演示边界

所有报告、模型结果、服务状态、任务计数、分数和错误都为合成示例，不是当前系统的真实记录。原型不调用后端、不读取密钥、不运行模型；交互状态仅保留在当前页面内存，刷新重置。

- 选择文件仅展示文件名；映射预览固定为内置示例，界面已明确标记，不解析或上传文件。
- 创建、重试、复核与重新检测仅演示交互反馈。
- 导出按钮下载带有示例标识的 CSV。正式业务仍保留现有 XLSX 导出。
- 部分计数和配置用于固定布局演示，不作为业务统计契约。
- 本次只评审桌面 Web，不扩展其他端。
