# 医学报告质控 Web 视觉规范

2026-10-16，用户在 A + C 方案之后提供 Notion Style 提示词，前端当前统一采用 Notion 文档工具风格。面向 Web 浏览器，沿用 React、TypeScript、Vite、Tailwind CSS。

## 当前风格

- 固定侧栏：米色 `#f7f6f3`，展开 256px、收起 80px；当前导航用 `#e3e1db` 背景、`#d4d0c7` 完整边框和字重标识。
- 导航结构：主导航显示工作台、单份质控、批量任务、人工复核；运行配置位于底部系统导航，之后为收起按钮和操作者信息。收起状态保存在本机，图标保留名称提示。
- 窗口适配：1024px 及以上保持固定侧栏；小于 1024px 默认隐藏，通过顶栏按钮打开 256px 导航抽屉。支持遮罩、Esc、选择导航项关闭、Tab 焦点约束和焦点恢复；窄窗口状态不覆盖桌面收起偏好。
- 溢出处理：导航区与主内容独立滚动；侧栏在极短窗口下也可整体滚动。
- 阅读区：白色背景，深灰正文 `#37352f`，轻边框 `#e9e7e3`，6–8px 圆角，固定的微弱阴影。
- 报告与检索证据：正文 15px、2 倍行高、最大 72ch，保留原文和错误标记。
- 表格：保留紧凑布局、等宽 ID 和计数、直接可见的操作；配色和悬停统一为 Notion 风格。`Panel density="compact"` 只调整密度。
- 控件：透明底色，悬停背景 `#efedea`，按压背景 `#e3e1db`；150ms 颜色过渡，无位移、缩放或悬停边框/阴影变化。
- 卡片与复核列表：装饰性 `⋮⋮` 手柄在悬停或键盘聚焦时显示，使用 `aria-hidden`、不接收鼠标事件；不引入拖拽排序功能。
- 状态：采用低饱和度背景并保留文字；小字号文字选用更深的蓝、红、绿、琥珀色以保证对比度。
- 键盘焦点保留可见指示与偏移；`prefers-reduced-motion` 关闭过渡。
- 页面位置由顶部面包屑标识，移除重复的可视页面大标题；保留屏幕阅读器标题。页面操作通过共享插槽并入顶部栏右侧，不在正文中另占一行；移除顶栏重复的产品标签和日期，让位于操作。正文距顶栏 24px。操作较多且窗口较窄时，按钮组可横向滚动，不撑宽页面；切换页面自动清空旧操作。
- 不增加营销大标题、长说明、渐变、深色侧栏或装饰性指标。

## 提示词冲突处理

原提示词的 token 示例同时包含 `active:scale-95`、悬停阴影及蓝底按钮，与其“绝对禁止位移/缩放、悬停阴影跳变”和“透明按钮”要求冲突。以禁止项及交互规则为准：按钮只改变背景，所有元素位置保持稳定。固定侧栏提示词中的配色 token 适配当前 Notion 色板，沿用无位移、无缩放的交互约束。
