# 医学报告质控 Web 视觉与交互规范

2026-10-16，按已审核通过的 [HTML 原型](../prototypes/2026-10-16-web-redesign/index.html) 实施。框架为 React + TypeScript + Vite + Tailwind CSS，面向桌面 Web。

## 统一风格

采用 Corporate Clean 浅色基底，结合 Data Dense 表格、固定侧栏和原文 / 建议分屏。Notion 仅作为长文本阅读参考，Bento 仅用于工作台主辅列组织。各页面共用一套控件与色板。

- 画布 `#f5f7fa`，侧栏 `#f8fafc`，白色内容区；主色 `#2855bd`，正文 `#202b3b`，辅助文字 `#647287`，边框 `#e3e8ef`。
- 固定侧栏展开 256px、默认收起 88px，保留图标下方的导航文字；活动导航保留背景、完整边框和字重标识，侧栏可滚动。
- 顶栏 58px，页面操作并入面包屑右侧；正文不重复展示页面大标题或独占行的操作栏。
- 表格采用紧凑行、行内按钮、等宽 ID 和数值；搜索、状态筛选与排序共用工具栏。
- 工作台展示真实统计、近期任务、快捷入口和待复核建议分布，不引入原型示例数据。
- 报告正文 14px、行高 2.1、最大 72ch；完整原文与建议并排，复核按钮与导航紧邻结果区。
- 控件仅做 150ms 颜色变化，提供焦点、禁用、加载与错误状态；支持 reduced-motion。移除不具备拖拽功能的装饰手柄。
- 导入弹窗和证据抽屉保持现有字段映射、Top 10 报告全文、来源、键盘焦点约束与关闭行为。
- 保留现有窄窗口导航抽屉作为浏览器窗口缩小的回退，不增加其他端产品功能。

## 人工复核：任务 → 报告 → 四项检查

1. 入口按任务聚合，展示来源、报告总数、待复核报告数与待复核项目数。
2. 进入任务后显示报告表格，每份有效报告只占一行，包含原始行号、描述摘要、四项检查结果、待复核项目数；默认筛选待复核报告，可切换全部报告回看已处理记录。
3. 点击报告进入完整宽度的复核页，复用报告详情：顶部四项检查标签，左侧完整原文，右侧对应结果，下方复核按钮、历史与“下一条”。不再展示按单条建议拆分的侧栏。
4. 复核决定仍按检查项保存。接受一项不会替代该报告其他检查项的人工判断；只要有待复核项，报告就保留在待复核列表。暂缓继续计入待复核；新执行代际重新判断，历史决定保留。
5. 批量任务的检查结果和“发现异常 / 需复核”入口直达对应报告复核页，并激活人工复核导航；四项标签、“下一条”、刷新页面均保持任务、报告与分支身份。
6. 报告复核返回本任务报告列表，再返回聚合任务列表。支持 `/review/runs/{run_id}` 和 `/review/runs/{run_id}/reports/{run_report_id}/{branch}` 深链接。
7. 服务端先按报告去重筛选，再按原始行序分页；不在客户端截取单条建议列表做聚合，不为列表加载模型输出和证据大字段。

## “上一条 / 下一条”导航及接受状态

- 报告详情和报告复核共用前后导航，显示当前有效报告序号 / 总数。
- 仅在同一任务内移动；每次切换报告默认选中页面顺序中的第一个已启用检查项（通常为诊断一致性，未启用诊断时选下一项）。直接点击某个检查入口和手动切换标签仍定位到指定检查项。
- 导入报告按原文件行号排序，其他报告按创建时间与 ID 排序；两个方向均跨页查询、跳过无效导入行。
- 复核模式保留 `/review/runs/...` 路由。翻页不自动提交复核决定。
- 第一份禁用“上一条”；最后一份禁用向后导航并显示“已是最后一份”。保存和切换过程中禁用重复操作。
- 当前代际的最新决定为接受时，复核区显示绿色“已接受 / 本项复核已保存”，接受按钮改为绿色“已接受”且禁用。保存成功立即生效，即使随后的结果刷新失败也不能重复接受。
- 保留驳回、暂缓和编辑确认入口以修正判断；新的决定覆盖当前状态显示，历史记录继续保留。旧代际接受记录不锁定新代际结果。
- 导航接口查询顺序、前后 ID 与计数，不读取整批报告正文或模型输出。

## 数据与业务边界

所有生产页面使用现有 API 与真实任务数据，保留四项检查、单份提交、批量导入、失败行继续、重试、复核、证据和 XLSX 导出。任务列表新增服务端来源 / ID 搜索、状态筛选与时间排序；搜索转义通配符。演示数据仅存在独立原型和测试夹具中。

## 报告切换稳定性修复

- 报告详情按任务保留组件实例，检查分支不再作为整个页面的 React key，避免切换时重复读取任务、清空配置和重建页面操作。
- 每份报告共用一次原文查询，并行读取已有四项结果；分支切换复用当前报告 / 任务修订的内存结果。新报告、修订变化或手动重试会重新加载；复核提交后刷新当前结果。
- 任务配置未返回前不显示“未启用”。报告导航顺序也在详情页共享，避免每次切换标签重现“读取顺序”。
- 文档区记录当前窗口下已显示的高度，使用静态骨架保留加载位置，避免先缩成短提示框再撑开。较长结果仍可自然扩展；窗口宽度变化时重新测量。
- 切换报告时取消上一轮请求，不显示旧报告复核按钮；后台分支读取失败只影响该分支，当前分支提供重试与错误详情。
- 验证：24 项前端测试、8 项端到端测试与生产构建通过。真实页面给请求增加 300ms 延迟后，连续切换 12 次不新增请求、不闪回加载框；下一条等待期间文档高度保持 755.625px，快速换分支保留最终选择。1280 / 1440 / 1920px 无横向溢出。记录位于 `var/acceptance/report-switch-20261016/`。
