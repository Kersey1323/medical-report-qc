# Light SaaS 全站视觉主题

参考用户提供的 [Design Prompts](https://www.designprompts.dev/) Light → SaaS 提示词（文档内标题为 Minimalist Modern）。本主题替换韩式极简配色，应用于首页、单份质控、批量任务、任务详情、人工复核、报告结果、运行配置、上传弹窗及证据抽屉。

## 阅读与视觉规范

- 页面底色 `#FAFAFA`，白色卡片，正文 `#0F172A`，边框 `#E2E8F0`；以明确的表面层次和标题字重改善阅读。
- 蓝色 `#0052FF` 用于操作、导航和选中状态。主按钮渐变终点使用较深的 `#3565DB`，保证白色按钮文字对比度不低于 5.2:1。
- 次级文字从参考色微调为 `#5D6D83`，在浅灰 `#F1F5F9` 上的对比度约 4.82:1。
- 正文采用 Inter / 系统无衬线 / 中文系统字体回退，不新增外部字体网络请求。首页展示标题采用 Georgia / 中文宋体回退；业务标题保持无衬线、600 字重。
- 表格正文 14px，元信息至少 12px，报告原文与建议正文 16px；检索证据正文 15px。报告行距 1.95，避免细字、小字和过低对比度。
- 保持紧凑的桌面业务布局，侧栏 256px、默认折叠为 88px，图标在上、导航文字在下。按钮与卡片采用 8–14px 圆角、细边框和轻阴影。
- 工作台展示真实统计与近期任务，顶部介绍和插画已移除；复核概览与其他卡片统一为白色表面、深色正文及浅蓝操作按钮，全站保持浅色。
- 成功、异常、失败使用绿、琥珀、红色，并保留状态图标和文字。已接受建议继续禁用操作按钮；人工复核面板保持白底和中性边框，仅状态标识与已接受按钮使用浅绿色。
- 控件反馈约 150–200ms，页面/报告使用透明度入场；不移动报告布局。支持 reduced-motion。

## 实现位置

全站变量与业务组件在 `frontend/src/styles.css`，首页在 `frontend/src/pages/overview.css`。共享 Button、Panel、表单输入、搜索框和 Radix Select 继承同一主题。业务路由、任务聚合、前后条切换、数据接口及复核保存逻辑沿用已有实现。

## 验证

- TypeScript 与 Vite 构建通过，30 项前端单元测试通过。
- 搜索框整体焦点、下拉菜单键盘选择、取消映射、长列表滚动及 Escape 关闭层级的浏览器测试通过。
- 1280、1440、1920 宽度下检查首页、单份、批量、复核任务列表、任务内报告列表、任务详情、运行配置、报告复核及证据抽屉，共 27 个页面状态，无页面横向溢出或运行异常。
- 实际报告的已接受按钮禁用、正文 16px 已验证。浏览器验收只读取已有数据，上传交互使用模拟接口。
