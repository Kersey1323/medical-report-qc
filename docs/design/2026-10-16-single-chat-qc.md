# 单份即时质控：会话与纵向时间线

## 新业务约定

用户明确单份质控由用户在当前页面等待，不必创建持久化任务。`#single` 改为一次性报告会话：底部填写影像描述与医生诊断、选择检查项目，中间呈现原始报告消息、纵向时间线和各分支结果。参考 Timeline Vertical showcase 的细连接线、状态节点与阶段时间，配色保持现有 Light SaaS。

此次单份入口不再调用 reports/runs/start，不写业务 Report、QualityRun、RunReport、ModuleResult、InferenceAttempt、CandidateCache、CSC chunk 或复核记录，不加入任务列表和统计。原有批量任务、历史单份记录及持久化 API 沿用原流程；不删除既有数据。

## 流式接口与执行

`POST /api/v1/single/stream`：请求包含 description、diagnosis、checks，默认四项。HTTP 200 返回 application/x-ndjson，每行沿用 status/data/detail/request_id 封装。

- 事件：start、preflight、branch、stage、result、complete，以及保持连接的 heartbeat。
- stage 包含真实分支、阶段、片段标识、尝试次数、时间、成功/失败/重试状态；不伪造百分比或模型思考过程。
- 单项失败以 result.outcome.error 返回，继续其他项；整个请求错误以 status=error/detail 返回。流中断且没有 complete 时，客户端标记未完整完成，不当作成功。
- 复用原四项 Pipeline、同一提示词与配置、医学事实约束、检索身份验证及过滤。仅替换为临时阶段执行与内存检索缓存，CSC 不配置持久化 chunk store。
- GPU/在线服务仍沿用各自并发与排队保护。每个 API worker 最多四个临时连接，事件队列有界；上游状态未知时禁止自动重发。
- 关闭连接、离开页面或停止按钮会取消等待与后续阶段。已发出的上游调用可能需要自行结束，不承诺立即中断远程 GPU/API 运算。
- 业务数据不落库；底层模型服务请求审计及脱敏运维日志遵循既有保留策略。刷新/离开页面不会恢复本次结果。

## 界面

时间线始终显示服务预检与所选检查，各阶段实时展开，结束后可展开查看。结果包含原文位置高亮、参考/修正文、编辑建议、覆盖信息、教师意见、检索正文与来源。提供复制建议及检查下一份；不提供持久化人工复核按钮。用户向上阅读、展开阶段或输出、打开详情时停止自动滚动，并提供查看最新进展入口。

桌面采用居中时间轴，每个节点左侧为流程卡片，右侧为同一流程的输出卡片；每一行独立对应，不设固定侧栏结果区。节点带统一序号与状态，卡片和节点悬停/焦点联动，滚动首次进入时轻淡入；减少动态效果偏好下取消入场动画。右侧默认两行摘要，点击展开更多内容；“查看详情”打开原生模态对话框，展示完整原文、建议、检索正文与来源、阶段记录和完整返回数据。Esc 关闭后焦点返回触发按钮。提交后输入区收起，底部保留停止或检查下一份。

### 按执行推进呈现与自动跟随

- 初始仅显示服务预检流程；收到真实完成事件后呈现对应输出，下一项开始后再呈现其流程卡片。未开始的检查不显示占位卡片，停止不会凭空展示后续项目。
- 卡片按流程、输出的顺序逐个加入，每步相隔 240ms；滚动进入视口时 200ms 淡入，已经出现的卡片不重复动画。减少动态效果模式取消延迟和滚动动效。
- 卡片使用白色背景；节点和小标签以蓝色标记执行中、绿色标记完成、琥珀标记发现异常、红色标记执行失败，同时保留文字和图标状态。
- 会话随内容增高平滑滚动。手动向上滚动、展开内容或打开详情时暂停跟随，通过“查看最新进展”恢复，避免打断阅读。
- 构建、33 项单元测试及 8 项浏览器测试通过；新增受控事件流验证未开始项隐藏、先输出后下一流程、状态配色、自动滚动、手动暂停与恢复，以及减少动态效果模式。截图位于 `var/acceptance/single-progressive-20261016/`。
