# Light SaaS 展示主页

用户于 2026-10-16 要求新增更具展示感的主页，参考 Design Prompts 的 Light → SaaS，并加入论文内容。

## 页面与入口

- 无 hash 的默认入口及 `#home` 展示独立主页；原有 `#overview` 保留工作台。
- 主页采用顶栏，不加载业务侧栏或统计接口。后端不可用时仍可展示。
- 业务侧栏新增“首页”；主页提供单份质控、工作台、批量任务入口。
- 页内导航滚动到质控能力、研究方法、工作流程，避免与 hash 业务路由冲突。

## 内容来源

根据用户提供的《毕设v5.1.docx》及已确认的重建规格，介绍第三章诊断生成参照、第四章领域适配与 C2EC 字符纠错、第五章教师知识和检索增强的语法纠错与错误定位。

章节内容是论文方法概述，不宣称所有训练方法对应当前部署产物，不展示未经验证的性能数字。首页插画标为流程示意，不使用患者文本或伪造运行结果。实际模型配置在工作台查看。

## 视觉与交互

白色和浅蓝表面、蓝色渐变、柔和光晕、报告 SVG 插画及轻量浮动动画。主页使用独立 `landing.css`，不改变业务工作区密度。所有动画遵循 reduced-motion；章节选项支持左右键、Home/End 及标准 tab/tabpanel 语义。

## 验证

- TypeScript / Vite 构建和现有 30 项单元测试通过。
- `frontend/e2e/landing.spec.ts` 验证无后端入口、章节键盘切换、刷新、业务路由与浏览器返回。
- 1280、1440、1920 宽度下检查主视觉、章节和工作流，无横向溢出；减弱动态模式无连续动画。
- 截图：`var/acceptance/landing-saas-20261016/`。

## 滚动显现与工作台精简

主页使用自身滚动容器作为 IntersectionObserver 根节点。参照 Corporate Clean showcase：标题、能力卡片、方法介绍和流程在进入有效视口 15% 时淡入上移 20px，时长 500ms、ease-out，同组卡片按 50ms 间隔出现，最长错开 150ms。每个元素首次显现后停止观察，向上滚动不淡出、不重播。首屏在首次绘制前设置隐藏起点，待起点绘制后触发入场，保证刷新时标题和插画同样淡入。变化仅涉及透明度和视觉位移，不改变文档布局；键盘焦点进入时立即呈现内容。减少动态效果偏好可即时切换，缺少观察器时内容默认可见。

工作台删除原顶部介绍、日期与插画，直接显示统计卡片和任务列表。单份与批量业务入口仍在侧栏，主页也提供入口。

补充浏览器验收通过：首次加载和刷新首屏透明度过渡、离开后保持可见、滚回不重播、卡片错落延迟、滚动高度稳定、动态切换 reduced-motion、统计区域置顶，以及原有主页导航与键盘章节切换。

动画参考：https://www.stylekit.top/styles/corporate-clean/showcase （核对其展示页的 IntersectionObserver 触发比例、一次性停止观察、位移、时长与错落参数）。
